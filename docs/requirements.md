## 一、产品定位

不是笔记平台，而是面向备考/学习场景的**超级学习助手**：以智能体为核心，结合平台提供的存储展示服务与各类 Skill，覆盖"看课 → 出笔记 → 刷题 → 复盘补弱"的完整学习过程。

## 二、系统构成

- **智能体平面**：TRAE 等任意 Agent（免费），负责全部生成与分析，经 MCP / Skill 与系统通信。
- **展示交互平面（本系统）**：多用户，负责账号、内容存储、展示与交互（批注、刷题、判分、错题、组卷）。

```
任意 Agent（生成目录/笔记/批注/习题，复盘分析）
      ▲ ▼ 凭证接入 → 服务下发 Skill + 提示词 + MCP
本系统（多用户：存储 + 展示 + 交互，数据按用户隔离）
```

## 三、用户系统与登录流程（v7.1 更新）

### 3.1 账号体系（为计费打基础）

- 系统后期按订阅收费（如按月付费），因此必须有账号体系：**支持注册 + 账号密码登录**。
- 注册：账号（手机号 / 邮箱 / 用户名）+ 密码 + 确认密码；注册成功后切回登录。
- 登录：账号 + 密码，校验通过后进入下一步。

### 3.2 登录页（独立页面，不用主页当背景）

- 登录/注册是**独立设计的全屏页面**，覆盖在主页之上：
  - 左侧品牌区：Logo、产品标语、核心能力介绍（AI 生成内容 / 刷题批注 / 错题归集 / Agent 接入）、学习闭环示意。
  - 右侧登录卡片：登录 / 注册双 Tab 切换，账号密码表单。
- 未登录时看不到主页内容。

### 3.3 完整流程

```
注册 → 登录 →（登录页原地切换第二步）手写考试目标 + 考试日期 → 进入系统 → 弹出 Agent 接入凭证
```

1. **登录成功后在登录卡片内切换到第二步"创建备考空间"**（带步骤指示 ①账号登录 ✓ → ②创建备考空间）：
   - 考试目标：**手写填写**（如"软考 · 系统架构设计师"）。不做下拉枚举——平台无法穷举所有考试目标，只要用户写清楚即可。
   - 考试日期：日期选择。
2. 确认后进入系统，自动完成：
   - **左上角创建备考空间**：空间名即所填考试目标，徽章"备考中"。
   - **开启考试倒计时**：侧边栏倒计时卡片（大号天数 + 考试日期）与顶栏徽章（⏳ 距离考试 N 天），按考试日期实时计算。
   - **弹出 Agent 接入弹框**：见第四节。
3. 登录用户显示在侧边栏底部（头像 + 账号名）。

### 3.4 再次入口（必须可找回）

用户可能当时点了"稍后接入"或没设置完整，之后必须能重新找到设置入口：

| 入口 | 打开内容 |
|:---|:---|
| 左下角头像菜单 →「🔌 Agent 接入凭证」 | 重新打开接入弹框，重新复制凭证 |
| 左下角头像菜单 →「🎯 考试目标设置」 | 修改考试目标与考试日期（倒计时同步更新） |
| 左下角头像菜单 →「👋 退出登录」 | 退出当前账号，回到登录页 |
| 点击左上角工作空间 / 倒计时卡片 | 同"考试目标设置" |

- "稍后接入"按钮的提示文案需指明再次入口位置（左下角头像菜单）。

## 四、Agent 接入流程（新增 · 核心）

1. 登录进系统时自动弹出**接入弹框**，内含一段可复制的**接入凭证**，内容包括：
   - MCP 端点地址；
   - 用户凭证（token，与当前登录用户绑定）；
   - 绑定用户与考试目标说明；
   - 接入说明（服务将下发 Skill、提示词、MCP 工具）。
2. 用户**复制凭证**，把它交给任意一个 Agent（如 TRAE）。
3. Agent 凭该凭证**自动访问我们的服务**；服务校验凭证后，把**对应的 Skill、提示词、MCP 配置**返回给该 Agent。
4. Agent 装配完成后，即可以**当前登录用户的名义**与系统交互：生成目录/笔记/批注/习题、读取错题与答题事件、发起复盘。

**安全与隔离（硬性要求）**
- 每用户一个 token，服务端所有接口凭 token 识别用户。
- Agent 的一切读写只作用于该 token 对应用户的数据，**不同用户之间严格隔离，不能串数据**。
- token 支持重置/吊销；凭证文案中需明示"仅对当前登录用户有效"。

## 五、数据来源边界（新增 · 核心）

### 5.1 AI 生成的数据（由 Agent 经 MCP 写入）

| 数据 | 说明 |
|:---|:---|
| 目录结构 | 课程文件夹，如"架构师综合知识精讲""案例分析专项" |
| 文件名 | 每一集，如"第3集 软件架构风格" |
| 笔记内容 | 本集框架 / 知识卡片 / 速查表 / 考试提示 |
| AI 批注 | 笔记中的老师强调、考点标注 |
| 每集习题 | 带答案与解析，随笔记一起生成 |

### 5.2 使用过程数据（由本系统在用户使用中产生）

| 数据 | 来源 |
|:---|:---|
| 刷题记录 | 用户在刷题中的作答与本地判分 |
| 错题本 | 刷题 / 模考答错自动归集 |
| 组卷 / 模考记录 | 从题库选题组卷、模考作答与成绩 |
| 我的批注 | 用户在笔记上补充的个人批注 |

### 5.3 数据流

```
AI 生成每集笔记 + 习题
        ↓ 习题进入题库（按集归属）
刷题（如"第1集 软件架构概念"范围 = 该集 AI 生成的习题）
        ↓ 答错自动归集
错题本 ←──────── 模考交卷判分
        ↓（题库 = AI 生成题 + 错题标记）
组卷：从题库筛选题目组合成模拟试卷 → 模考
        ↓ 答题事件
Agent 读取事件 → 复盘诊断 → 生成补充内容写回系统
```

要点：**刷题、错题本、组卷本身不存储"源题目"，题目全部来自 AI 为各集生成的习题；这三个模块消费的是使用过程中产生的作答/错题/组卷数据。**

## 六、学习闭环

1. Agent 生成笔记（带 AI 批注）、习题（带答案与解析），写入系统。
2. 用户看笔记（可补充个人批注）、刷题（系统本地判对错、收错题）。
3. 学完一个章节，用户向 Agent 发起复盘。
4. Agent 读取该章节对错事件 → 诊断薄弱点 → 给出建议。
5. Agent 生成补充知识点与针对性习题，写回系统。

## 七、UI 需求要点（对应原型 v3 柔和版）

- **笔记页**
  - 去掉"生成习题""生成记忆卡片"按钮：生成动作由 Agent 侧发起，UI 不提供手动生成入口。
  - 批注可交互：选中正文文字 → 出现浮动"✏️ 批注"按钮 → 弹窗填写 → 保存后原文高亮（我的批注用紫色底纹，区别于 AI 批注的金色底纹）。
  - 点击任意批注 → 详情弹窗：显示批注原文、批注内容与类型（AI 批注 / 我的批注）；我的批注可删除；AI 批注可"让 AI 解释"（转给 Agent）。
  - 笔记元信息标注"AI 生成"与来源（B站视频 → AI 生成笔记与批注）。
- **刷题页**：搜索式集数/范围选择器；顶部提示题库来源 = AI 为每集笔记生成的习题。
- **错题本**：重做为单题弹窗（不跳刷题页）；提示数据来自使用过程。
- **组卷页**：自动补齐、预览试卷、开始模考、模考判分全流程可响应；提示题目来自题库（AI 生成题 + 错题）。
- **登录页（独立全屏页面：品牌区 + 登录/注册卡片 + 第二步创建备考空间）、考试目标设置弹窗、Agent 接入弹窗、头像菜单（再次入口）、考试倒计时**：见第三、四节。
- 目录树可折叠；整体视觉为 v3 柔和版（暖米色底 + 淡紫主色 + 圆角卡片）。

## 八、数据模型

| 表 | 关键字段 |
|:---|:---|
| users | id, account, password_hash, nickname |
| tokens | id, user_id, token, created_at, revoked_at |
| workspaces | id, user_id, name（一件事一个空间）, exam_goal（手写文本）, exam_date |
| items | id, workspace_id, parent_id（可自由嵌套）, kind, name, content, source（ai/user） |
| annotations | id, item_id, user_id, anchor, text, source（ai/user） |
| events | id, user_id, item_id, action（annotate/answer/reveal/wrong）, payload, created_at |

- kind：note（笔记）/ quiz（习题），可扩展新类型。
- 存储自由创建；**UI 呈现方式不与存储结构绑定，UI/UX 另行设计**（已定 v3 柔和版）。

## 九、MCP 接口

create_workspace / create_item / write_item / read_item / list_items / get_events / report_status。

- Agent 持 token 接入时，服务端自动下发 Skill、提示词与 MCP 工具清单。
- 所有接口按 token 识别用户，数据按用户隔离。

## 十二、安卓端设计（v7.2 新增 · 原型已完成）

### 12.1 范围

- **当前只设计安卓端**（手机 + 折叠屏手机），iOS 与桌面端另行安排。
- 视觉沿用 v3 柔和版（暖米底 #F7F5F0 + 淡紫主色 + 圆角卡片 + 柔和阴影）。
- 功能范围与桌面端一致：登录注册、考试目标、Agent 接入、笔记批注、刷题、错题本、组卷模考。

### 12.2 信息架构

- **底部导航 5 Tab**：笔记 / 刷题 / 错题本 / 组卷 / 我的。
- **弹窗一律 Bottom Sheet（底部抽屉）**：集数选择、Agent 接入、考试目标设置、批注编辑、批注详情、试卷预览、模考结果。
- **全屏覆盖页**：登录页、模考、错题重做。

### 12.3 页面清单

| 页面 | 要点 |
|:---|:---|
| 登录页 | 独立全屏：品牌区（标语 + 能力标签）+ 登录/注册 Tab；登录后原地切换第二步"手写考试目标 + 日期" |
| 笔记 | 倒计时卡 + 可折叠目录（AI 生成标注）→ 笔记详情；批注模式见 12.4 |
| 刷题 | 范围条（点击开搜索 Sheet）+ 题卡 + 即时判分 + 解析 + 自动入错题本 |
| 错题本 | 列表（错次/来源集）+ 重做（全屏单题，不跳刷题）+ 掌握标记 |
| 组卷 | 来源/题型/范围 chips + 数量步进 + 自动补齐 75 题 / 预览试卷 / 开始模考 |
| 模考 | 计时器 + 题号导航 + 交卷判分 + 错题自动归集 |
| 我的 | 头像/目标、倒计时、Agent 接入凭证、考试目标设置、学习统计、订阅计费（占位）、退出登录 |

### 12.4 与桌面端的交互差异

| 场景 | 桌面端 | 安卓端 |
|:---|:---|:---|
| 批注 | 选中文字 → 浮动按钮 | 入口在笔记顶栏右侧「✏️ 批注」→ 进入批注模式 → 点击段落/知识卡片添加（移动端框选文字难操作，不做悬浮按钮） |
| 集数选择 | 搜索式下拉面板 | 搜索 Bottom Sheet（带分组与题数） |
| 再次入口 | 左下角头像菜单 | 「我的」页菜单 + 倒计时卡点击 |
| 生成入口 | 无（Agent 发起） | 无（与桌面端一致） |

### 12.5 折叠屏适配

- **断点**：宽度 ≥600dp 视为展开态（覆盖主流竖向折叠屏内屏），真机按 WindowSizeClass 自动切换；原型提供折叠态 390dp / 展开态 780dp 手动切换演示。
- **展开态变化**：
  - 笔记：双栏分屏（左目录 316dp + 右笔记详情），无需来回跳转；
  - 错题本、组卷：双列网格 / 双列布局；
  - Bottom Sheet：由全宽变为 560dp 居中卡片；
  - 题卡等内容：限宽 620dp 居中，避免行长过长；
  - 展开/折叠切换时保持当前页面与数据状态不丢失。
- 分屏 / 多窗口模式按同一 ≥600dp 规则处理。

### 12.6 安卓实现建议（供编码参考）

- Kotlin + Jetpack Compose，Material 3 规范，配色映射 v3 柔和版色板。
- 布局分支用 WindowSizeClass（Compact 单栏 / Medium 及以上双栏）。
- 本地缓存 Room，登录态与 token 存 EncryptedSharedPreferences；MCP 交互走后端，不在端上直连。
